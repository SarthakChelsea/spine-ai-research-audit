# Mihir Review: Decisions Needed Before Pilot

## Requested clinical decisions

1. Which pain measures count as adequate for pain phenotyping: any named scale, only validated patient-reported instrument, or a tiered classification?
2. Which psychiatric/biopsychosocial factors are mandatory versus desirable for a pain-focused dataset?
3. Which treatments count as complementary/integrative care for this audit?
4. Does physical therapy alone count as integrative care, or should it be recorded as rehabilitation and analyzed separately?
5. What minimum outcome/follow-up information is necessary before we call a resource fit for treatment-response research?
6. Which confounders are minimally necessary before we call a resource fit for observational treatment-selection research?
7. Should postoperative imaging datasets be assessed separately from pre-treatment prognosis datasets?

## Proposed decision principle

The audit should be intentionally conservative: when key timing, outcome, or linkage information is absent, the resource is classified as `not_supported` for the corresponding causal/prognostic use rather than upgraded based on plausible but undocumented clinical context.
